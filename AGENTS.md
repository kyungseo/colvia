# Agent Entry

## Colvia source development

In a trusted Colvia source checkout, start with [Contributing](CONTRIBUTING.md), the [development index](docs/development/README.md), and the exact record that owns the task. Follow the [source workflow](docs/development/WORKFLOW.md) and [document and artifact placement](docs/development/document-ownership.md). Source work does not require installing Colvia or creating records in an installed project.

The human Owner decides material scope, result acceptance, and publication. Preserve source, existing records, and partial or unknown states. Keep credentials and private material out of source, examples, review packets, and public reports. Apply the authorization and review requirements in the current source workflow.

## Work in a connected project

Follow the project rules and the guide from its verified launcher. Use the following commands in the connected project folder.

- macOS: run `./colvia guide`, then `./colvia ordinary list`.
- Windows PowerShell: run `.\colvia.cmd guide`, then `.\colvia.cmd ordinary list`.

The installed guide governs current Work. Use the [Preview manual](manual/en/README.md) for setup, approved Work, recovery, and supported environments. Use the [source documentation index](docs/README.md) to find the technical records for Colvia itself.
