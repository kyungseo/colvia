# Colvia

Colvia는 사람과 AI가 함께 일하는 로컬 워크플로 도구입니다.

Colvia is a local workflow tool for working with AI agents.

[한국어 안내](manual/ko/README.md) · [English guide](manual/en/README.md)

Codex나 Claude Code가 제안한 작업 범위를 승인하고, 결과를 검토해 받아들일지 결정합니다. 위에서 언어를 선택하면 설치와 연결, 첫 작업부터 새 대화에서 이어가기까지 순서대로 볼 수 있습니다. 업데이트, 연결 해제와 기록을 보존하는 제거 방법도 같은 안내에 있습니다.

Approve the scope proposed by Codex or Claude Code, then review the result and decide whether to accept it. Choose a language above for step-by-step help with setup, your first task, and picking up in a new chat. The same guide covers updates, disconnecting a project and removing Colvia while keeping its records.

macOS에서 Claude Code CLI 또는 Codex CLI를 쓰면 조정 에이전트가 승인된 작업자를 동시에 최대 두 개 실행하고 결과를 모읍니다. Windows 11 x64에서는 작업자를 직접 시작하고 파일 기반 통합 검사를 사용합니다. Windows 11 ARM64에서는 Work를 한 건씩 진행합니다.

With Claude Code CLI or Codex CLI on macOS, a coordinator runs up to two approved workers at a time and collects their results. On Windows 11 x64, start the workers yourself and use file-based integration checks. On Windows 11 ARM64, run individual Works.

[macOS·Windows x64: 제출본 2~8건 함께 수락·반영](manual/ko/work.md#grouped-acceptance) · [macOS and Windows x64: accept and apply 2–8 submissions together](manual/en/work.md#grouped-acceptance)
