# Using Colvia

Colvia keeps the work you agreed on, the result your agent prepared and your decision together. Open the connected project in Codex or Claude Code and ask what needs your review.

Start with [installation, project connection and your first Work](foundation-preview.md). The same guide covers retained contents, backups, Git, notifications and disconnection. It also explains the environments still awaiting verification.

Public installation commands will be published with the Preview. The [verification section](foundation-preview.md#target-platforms-and-verification-status) lists what was tested over private HTTPS and what is still unverified in host apps.
