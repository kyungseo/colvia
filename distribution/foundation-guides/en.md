# Using Colvia

Colvia is a local workflow tool for working with AI agents. Plan work with Codex or Claude Code, approve the scope, and review results before accepting them. Colvia keeps approvals and submissions on your device. Open the same project to pick up the work in a new chat or with another agent.

1. [Install and connect the folder](foundation-preview.md#install-and-connect-a-project). If your project uses Git, [ask the agent to register Git first](foundation-preview.md#register-git). In your usual chat, ask, “Connect this folder to Colvia.” Review the files Colvia will add and where it will store records before approving the connection.
2. [Say what you want to do in the current chat](foundation-preview.md#start-with-the-work-you-want-to-do). In an empty folder, a sentence such as “I want to summarize the meeting in one page” is enough to start. You can also connect a project you already work in. The agent uses any goal you’ve shared and the existing project material to propose a plan. Saving a plan keeps the existing contents of the files it lists. These contents and later submissions are kept in records and backups.
3. [Review the result and see the recorded follow-up](foundation-preview.md#delegate-and-review). Open the same project in a new chat to continue. The agent needs access to both the connected folder and the record folder.

For short questions and small corrections you request directly, check [when you can skip creating a Work](foundation-preview.md#start-with-the-work-you-want-to-do). Continue edits that belong to an existing Work using its records.

After installation, see [updates and recovery](foundation-preview.md#updating-and-recovering-an-interrupted-update), [disconnecting a project](foundation-preview.md#disconnect-a-project), and [removing Colvia while keeping records](foundation-preview.md#remove-colvia-and-keep-your-records).

If you moved the project folder, [ask your agent to reconnect the existing records at its new location](foundation-preview.md#continue-after-moving-a-project-folder) before starting new work.

See the [platform and agent access requirements](foundation-preview.md#target-platforms-and-verification-status) for your setup.
