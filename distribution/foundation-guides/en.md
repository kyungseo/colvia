# Using Colvia

Colvia keeps the work you agreed on, the result your agent prepared and your decision together. Open the connected project in Codex or Claude Code and ask what needs your review.

1. [Install and connect the folder](foundation-preview.md#install-and-connect-a-project). Review what Colvia will add before approving the connection.
2. [Ask for your first Work](foundation-preview.md#start-with-the-work-you-want-to-do). Before recording the plan, exclude confidential files. Colvia keeps existing contents of the files listed in a saved plan and keeps submitted contents in the record and its backups.
3. [Review the result and see the recorded follow-up](foundation-preview.md#delegate-and-review). Open the same project in a new chat to pick up the records.

If you moved the project folder, [check its new location](foundation-preview.md#continue-after-moving-a-project-folder) before starting new work.

Public installation commands will be published with the Preview. The [verification section](foundation-preview.md#target-platforms-and-verification-status) lists what was tested over private HTTPS and what is still unverified in host apps.
