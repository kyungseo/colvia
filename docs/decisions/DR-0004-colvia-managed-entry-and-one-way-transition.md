## Rationale

The chosen bounded transition changes the managed entry while preserving authority and record identities. An explicit new window and schema boundary make old-writer refusal and historical interpretation reviewable. The selected A policies avoid automatic record cancellation/rebinding and retain the existing receipt/staging mechanism; their operational costs are accepted explicitly rather than hidden behind a generic migration success claim.

### Physical Publication Proposal

Use exclusive direct creation for root N (`O_CREAT|O_EXCL|O_NOFOLLOW`, non-executable mode `0600` atomically at creation, with an unsupported umask refused before S1; do not create another mode and chmod it into an apparently supported initial prefix). This avoids a two-link canonical launcher and introduces no hardlink exception. The ownership rule for N is admission-confirmed absence plus the exact receipt, complete S3 release, B0 and unchanged truth. During exact recovery those facts and a table-matching regular-file prefix are sufficient; no independent proof of who created the same bytes is required. It is not general permission to repair a user file. Existing occupants during initial apply, aliases, symlinks, link count other than one, unknown modes and any nonmatching bytes are preserved and refused. Under this trusted-account/cooperating-writer model, byte-identical intervening substitutions cannot be authenticated as a different owner; do not claim otherwise.
