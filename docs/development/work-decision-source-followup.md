## When to revisit

A team can have two approved Works with the same title. A later decision can put one of them on hold. The current [Work manual](../../manual/en/work.md#resume) explains how to follow the decision to its approved file and how to ask which file it applies to when that link is missing.

If this still causes repeated confusion in practice, check the remaining case first. Give a fresh chat access to the latest team decision and two equally plausible approved Works, with no file or Work reference connecting the decision to either one. Check whether it asks which Work is affected, leaves both candidates untouched until answered, and can identify the independent Work that can continue. Keep an unsupported attribution distinct from a prudent decision to wait.

If finding or matching existing evidence repeatedly fails, consider a small reference from the Work to the decision source and its scope. If the team never recorded which Work it meant, the author still needs to clarify that fact. Candidate registration authorizes no implementation or automatic change to Work state.
