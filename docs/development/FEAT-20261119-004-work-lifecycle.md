# Pause, resume, discard and replace ordinary Work

Opening another Work is read-only. A lifecycle decision binds the confirmed action, reason, current Work, optional target Work, workspace registration, latest note and file observations to a preview. Apply publishes the current Work head and its latest lifecycle reference together. Replacement does not write the target Work or inherit its approval.

A versioned Work head carries the original plan, approval, submission and revision decision. Pausing records fingerprints for up to 128 approved paths. Copies and snapshots of project files are outside this operation. Resume restores the original phase; review uses a fresh receipt and the normal current-file check. Old projects retain their existing requirements until the first lifecycle decision. The latest lifecycle reference remains in backups after later ordinary transitions. Older readers must refuse a project with this capability.

The human list and startup guide use a current filter; unfiltered JSON retains its original list and cursor. Completed archived and discarded Work remain accessible by ID or in the full list. Only completed Work can be archived or restored from archive. Priority, dependencies and multi-user coordination have separate scope.

## Verification

Synthetic checks cover switching between three existing Works, notes and additional approvals across a pause, review receipts after file drift, revision requests, replacement chains and competing decisions, and filtered pagination. A paused destination blocks isolated application. An old notification can show the current disposition without accepting the submission. Uninstall retains its active-work protection while a Work is paused.

A backup written with the v0.2.0 source restored with the same original and submitted content. The amended Work round trip also checked an older open reader, older backup refusal, and restoration after the resumed submission was accepted. Three platform-shaped packages carried the same guide bytes as the source. These checks used local fixtures and the existing slot validators. Platform installation and publication have their own approval.

Review follow-up checked added edits and creations against the effective plan, the 128-path boundary and an unreadable observation. Git folder moves preserved paused active, paused review and discarded heads. A registered linked worktree with an independent Work can pause before an application binding exists. Live delegated work or a pending submission/application must be settled first. Current-list pagination keeps the filter in its cursor; reverse replacement lookup still scans recorded dispositions. Remeasure that lookup under the existing long-project observation item if it becomes costly.
