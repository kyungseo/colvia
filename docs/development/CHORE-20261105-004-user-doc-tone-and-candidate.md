## 구현·검토 결과

사용자 문서와 작성 지침 27개를 검토해 19개를 수정했다. 한영 매뉴얼 22개 중 첫 실습·추가 실습·재개·색인 8개는 그대로 유지했다. 나머지 매뉴얼, 세 README, 설치 문서 사용자 구간, 작성 지침에서 반복 검증 이력을 덜어내고 사용 조건과 행동을 앞세웠다. 일반 제한은 limits-en/limits-ko에 모으고 삭제·해제·취소·복구 조건은 해당 행동 옆에 유지했다. 과거 실습은 위 부록에 보존했고 이전 앵커는 현재 자료나 이력으로 연결한다.

설치 문서 생성기는 setup에서 추가된 limits 링크를 설치본 내부 앵커로 바꾼다. 한영 내용 해시 11쌍과 생성 사본을 대조했다. 에이전트 계약 18개, 문서 색인의 앞부분, 인용 예시·명령·Mermaid, 제거의 여섯 단계는 이번 단계 시작 상태와 동일하다. 설치본의 영어 구조 설명은 보호 대상 CONCEPTS를 계속 사용하며 한국어 사용자 설명과의 문체 차이를 의도적으로 유지한다. 지원 의미를 넓히지 않았다.

문서·설치 payload 집중 검사 8개가 통과했다. 최종 GFM 렌더에서 문서 28개와 로컬 링크·앵커 272개를 확인했고, 코드 밖에 해석되지 않은 강조 표시는 없었다. 기존 도식은 바이트가 같아 이전 렌더 근거를 재사용한다. 전체 런타임 회귀를 반복할 동작 변경은 없었다.

Claude CLI의 독립 정적 리뷰 D0–D4를 진행했다. D0의 계획 조건, D1의 범위·알림·배치 보정, D2의 문구·앵커 및 후보 검사 보강을 반영했다. D3에서 문서 검토를 마쳤으며 D4에서 아래 빌드 보정의 중대한 회귀가 없다는 의견을 받았다. 마지막으로 요청된 재사용 소스 대조도 수행했다. Reviewer 의견은 Owner 수락과 구분한다.

## 후보 구성 중 발견한 빌드 보정

첫 Windows 후보의 두 아키텍처 EXE에서 실제 빌드 경로가 발견됐다. 모듈 모드를 끈 Go 빌드를 GOPATH 밖에서 수행하면 trimpath를 적용해도 임시 패키지 식별값에 물리 경로가 남았다. 일반 사용자용 배포물 준비의 필수 보정으로 처리했다. runtime 소스나 기능 계약은 바꾸지 않았다.

컴파일 입력을 고정 import 경로에 놓고 정규화한 GOPATH와 PWD를 지정했다. 캐시는 패키지 밖에 두며 모듈 모드와 기존 Go 기본 설정은 유지했다. 빌더는 안정된 패키지 식별값, 개인 빌드 경로 부재와 표준 라이브러리만 사용하는 구성을 검사한 뒤 성공 메타데이터를 쓴다. 기존 두 아키텍처 아이콘 검사에 실제 EXE의 경로 누출 회귀 검사를 추가했다.

집중 회귀 검사 1개가 두 아키텍처를 빌드해 통과했다(unittest 8.432초, 실행기 wall time 8.57초). 실제 공급본을 사용한 새 ARM64·amd64 EXE도 별도로 생성했다. PE 내부 아이콘 8개와 group101, 재배치된 주소 및 PNG 바이트가 ICO 원본과 일치한다. 이전/새 Go 도구는 1.27.2로 같고 모든 build 설정과 내장 core.zip·catalog도 같다. 원래 후보와 재사용 시점의 소스 차이는 빌더와 해당 테스트 두 파일뿐임을 확인했다. 바뀌지 않은 자산·런타임 검사는 앞선 통과 근거를 재사용한다.

## 준비 완료와 다음 단계

Apple silicon Mac 패키지와 Windows ARM64·x64 로컬 후보를 구성했다. Mac의 ICNS를 포함한 앱은 strict ad-hoc 서명 검사를 통과했으며 관리 도구에 내장한 앱 바이트도 같다. 새 문서와 아이콘을 담은 후보, 출처·버전·크기·해시, 검사와 실패 근거는 비공개 작업 산출물에 보존했다. Mac 자산과 Windows 준비 소스는 변경 없이 재사용했다. Windows의 실패 EXE는 사용 금지로 구분했다.

공개 origin은 미정이므로 이 후보는 공개 배포본이 아니다. 서명·다운로드 경로·플랫폼 수락을 확정한 뒤 공개용 입력을 고정해야 한다. 실제 설치·알림 등록·OS 아이콘 표시·클릭·VM·정상 설정의 새 모델 사용자 여정은 이번에 실행하지 않았다. 다음 검증안에는 개인 전역 지침·메모리·셸·개발 도구에 기대지 않는 표준 계정, 새 진입과 실제 압축, 새/이전 알림 등록, 밝은/어두운 화면 및 Windows 배율, 실제 x64 구분을 포함했다.

구현·독립 검토·로컬 후보 준비는 완료했고 Owner 결과 수락은 대기한다. 실제 설치 변경·Git commit/push·병합·공개는 수행하지 않았다. 전역 개인 지침은 이 제품과 별개인 한영 문안으로 준비했으며 Owner 문안 확정 전에는 원본을 바꾸지 않는다. 에이전트 행동 계약의 추가 정리는 별도 범위다.
