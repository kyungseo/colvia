# 기록을 보존하는 설치본 제거·재설치

## Owner 계획 결정 · 2026-11-16

등록판 `record-preserving-uninstall-r1`. 첫 Preview에서는 프로젝트 연결 해제와 알림 끄기를 안내한다. 설치본 제거와 기록 보존 재설치는 첫 Preview 이후 **P0로** 등록한다. 기존 자격증명 차단 후보도 P0다. 구현 범위와 검증은 해당 후속을 선택할 때 확정한다.

## 재개 조건과 완료 기준

- 한 표준 계정의 기본 관리 홈을 대상으로 제거·보존 항목을 미리 보여 주고 사용자 확인을 받는다. 관리·런타임 잠금과 소유권을 다시 확인한다. 실행 중인 작업, 미완료 갱신·복원·Git 반영, 사용 중이거나 바뀐 파일을 만나면 보존한 채 중단한다. 해당 계정에서 Colvia가 설치한 실행기·런타임과 소유권이 확인된 알림 등록만 정리한다. 중단된 작업은 기록으로 상태를 확인하고 같은 작업에서 이어간다.
- 사용자 파일과 Git, Work·승인·제출 본문·설정·백업·필요한 복구본을 유지한다. 설치 채널과 신뢰 정보, 기존 버전의 역행을 막는 상태도 보존한다. 프로젝트 연결은 기본으로 유지한다. 연결 해제까지 선택한 경우 기존 해제 절차를 사용하며, 이전 Work를 나중에 이어갈 계획이면 해제 전에 백업을 확인한다.
- [명시적 설치 복구](../../src/colvia/updates/installation.py#L241)의 기존 서명·버전·기록 호환 검사를 재사용한다. [실행기 교체](../../src/colvia/updates/native_entry.py#L41)는 현재 기존 파일을 요구한다. 검증된 제거 기록이 가리키는 Colvia 파일에 한해 없는 실행기를 다시 마련할 수 있도록 한다. 공식 재설치 후 같은 프로젝트에서 기존 Work·승인·제출 본문을 열어 확인한다.
- 로컬에서 정상·중단·소유권 변경을 집중 검사한다. 새 제거·재설치 흐름은 macOS ARM64, Windows x64·ARM64에서 각각 한 번 확인한다. 첫 설치·이전 Git·호스트 시험은 적용되는 근거를 재사용한다. 기록 영구 삭제와 공유 런타임 제거는 별도 범위다.
