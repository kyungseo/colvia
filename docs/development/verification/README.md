# Verification controls and evidence

These directories preserve controls and evidence for specific candidates. For current Preview results, see [product evidence and follow-ups](../product-evidence-and-followups.md#record-foundation-verification).

| Directory | Contents |
| --- | --- |
| [Binding and permissions](binding-permissions-controls/README.md) | Runner controls and dated authorizations. The L and P payloads under `fixtures/` are test inputs; their manuals and agent instructions belong to the respective fixture. |
| [Project entry](colvia-entry/README.md) | Conditions for checking project entry, including input identity, access, preflight and failure limits. |
| [Host qualification](u2-host/README.md) | Candidate-specific host, document editing and human recovery checks, with original English and Korean sections. |

Write new operator instructions and result summaries in English. Preserve the original wording of prior authorizations and reviewer responses. Treat copies of documentation inside a fixture as input bytes when checking a historical result. See the [repository language conventions](../document-ownership.md#document-language).
