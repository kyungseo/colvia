## 공개 전 필수 조건

2026-11-03 Owner 결정(revision 1). 첫 공개 전에 알림의 ‘보기’ 또는 본문을 눌렀을 때 정확히 그 알림이 가리키는 Work의 결과 상세가 열려야 한다. 문구 보완은 당장 결과를 찾기 쉽게 하는 중간 조치다.

공개 후보를 고정하기 전에 이 항목을 개발 범위에 넣고, 공개 판단 때 네이티브 클릭 근거를 확인한다. macOS와 지원을 표기할 Windows 11 환경에서 서로 구별되는 제출 A와 B를 준비한다. 작업자와 상세 창이 종료된 뒤 오래된 A 알림을 실제로 눌러 A의 결과를 확인하고, 창이 열린 상태에서 B를 눌러 B로 전환되는지 확인한다. 클릭은 조회만 수행한다. 알림 API 반환·수신함 단독 조회·다른 플랫폼의 결과로 클릭 검증을 대체하지 않는다. Windows ARM64와 x64의 실제 확인 범위를 구분한다. 근거가 부족하면 해당 공개 결정은 보류한다.

Codex와 Claude Code에서 각각 Work를 맡기고, 같은 공개 후보에서 해당 알림을 실제 클릭해 올바른 결과가 열리는지 확인한다. 근거에는 맡긴 도구, OS·아키텍처, 알림과 열린 제출의 대응, 클릭 전후 Work 상태를 남긴다. 공개할 macOS, Windows 11 ARM64, Windows 11 x64를 각각 구분하고 각 환경에서 두 도구 모두 상세 창 종료 후 열기와 열린 창 전환을 확인한다. 같은 시험 환경과 합성 자료는 재사용하되 도구·클릭별 결과는 따로 남긴다. x64 외부 확인은 최종 후보와 절차를 준비한 뒤 한 번의 일정에 묶는다. 한 도구의 성공이나 Claude의 정적 리뷰로 다른 도구의 실제 관측을 대체하지 않는다.
