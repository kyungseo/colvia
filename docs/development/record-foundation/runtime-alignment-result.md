# 전용 runtime 정렬·제한된 실행 검증 결과

전용 runtime의 버전 허용을 정렬했고, 실제 sandbox 작업자의 준비·제품 종료와 문서 처리 5단계를 확인했다. Claude는 수락한 보고서를 변경 없이 조회했지만, 시험 도구의 미지원 진행 이벤트 때문에 최종 답변 전에 중단됐다. 제품 조회 성공과 대화 완료는 구분한다. 이 결과는 Owner 수락 전이다.

## 변경과 확인 범위

| 항목 | 결과 | 한계 |
| --- | --- | --- |
| 버전 조건 | 슬롯 검사기와 배포 생성기가 같은 조건을 사용한다. macOS ARM64 전용 Python 3.14.10을 후보로 허용한다 | 실제 설치 슬롯 자격·공개 지원 선언이 아니다. 기존 3.14.6/3.14.7 및 Windows 조건은 유지한다 |
| 공급 대조 | 기존 archive와 파일·링크 1,701개 일치, 추가 0개. 전체 Mach-O 10개의 의존 경로를 대조했다 | 기존 비공개 공급 근거와의 일치이며 새 서명 배포 검증을 대신하지 않는다 |
| 전용 실행환경 | 격리 실행에서 Python 3.14.10·SQLite 3.53.1 확인 | 원 runtime의 내부 symlink 9개가 있는 상태다. 정규화된 새 설치 슬롯이 아니다. `-I -S -B` 확인은 site 의존 동작의 검증이 아니다 |
| 네이티브 준비·종료 | 약 1.49초. 준비 후 살아 있는 동일 신원의 프로세스를 제품 종료 경로로 종료했다. 종료값 -15와 그룹 부재 확인 | 실행 당시 실제 출력된 sandbox 정책에 한정한다. 기존 개인 Python 실패의 정확한 정책 원인이 확정된 것은 아니다 |
| 문서 처리 | 약 8.67초. 읽기·쓰기와 DOC-LINKS/GFM/CLAIMS 총 5단계를 통과했다. 원본 보존 확인 | 모델 실행 없이 기존 합성 흐름을 사용했다. Work는 active이며 결과를 자동 수락하지 않았다 |
| Claude 조회 | 약 8.19초. 지정 조회 1회와 성공 응답 1회, 동일한 수락 결과·보존 본문 확인. 프로젝트·기록 저장소 전후 동일 | 최종 답변 전에 `thinking_tokens` 이벤트를 시험 도구가 거부했다. 원 실행은 `ok=false`이며 대화 완료는 미검증이다 |

제품·시험 변경은 버전 검사 2개 파일과 관련 시험 3개 파일이다. sandbox template와 제품 process port는 바꾸지 않았다. 원본, 이전 실패, 실행 당시 코드·입력과 로그는 보존했다. 실제 설치·권한/설정 변경·키 생성·알림·커밋·공개는 수행하지 않았다.

## 집중 검사와 독립 리뷰

- 제품 영향 경로 33개 검사 통과. 버전 문자열, 플랫폼, SQLite 하한, 목록 무결성, 실제 Python/SQLite/경로 일치 조건을 확인했다.
- 연결부 20개, 네이티브 게이트 5개, 결과 리뷰 후 거부 사례 11개 검사 통과. 이전 18개 연결부 결과와 합산하지 않는다.
- 이전 공통 시험 코드와 현재 코드의 차이를 발견해, 기존 44개 검사를 현재 모듈에 오프라인 적용했다. 모두 통과했다. 원래 결과와 같은 코드라는 재사용 주장은 철회한다.
- 첫 계획 리뷰는 240초에 응답 없이 중단됐다. 원본을 보존하고 Owner가 승인한 축소 계획 리뷰를 110.587초에 완료했다. 결과 리뷰는 135.765초에 완료했으며 입력 drift는 없었다.
- 리뷰는 패킷 기반 정적 판단이다. 리뷰 후 시험 도구 보정은 Driver가 오프라인 검증했으며, 보정본의 실제 모델 재검증이나 추가 Reviewer 판정으로 확대하지 않는다.

알 수 없는 진행 이벤트를 계속 관측하도록 바꾸는 제안은 이번에 적용하지 않았다. 현재 실패 시 즉시 중단 조건을 유지한다. 나중에 중단 정책을 바꾼다면 제품 실패·에이전트 위반·시험 도구 스키마 미지원 상태를 분리해야 한다.

## 남은 조건과 다음 순서

1. 이번 소스 정렬과 제한된 실행 결과의 수락을 분리해 기록한다. 전체 Work 완료나 공개 준비 완료는 아니다.
2. Claude의 최종 자연어 답변 확인은 후속 행동 검증 1건으로 남긴다. 수정한 시험 도구는 오프라인만 검증됐고 기존 실행을 성공으로 소급하지 않는다. 이번에는 재호출하지 않았다.
3. 실제 설치본의 정규화 runtime, 최소 sandbox 정책, CLI·앱 및 Windows 검증을 공개 후보 단계에서 확인한다. 소스 실행 성공으로 대체하지 않는다.
4. 미완료 외부 효과가 있는 복원본의 활성화는 계속 보류한다. 현행 조회 전용 경계를 유지한다.

## 이전 중단 시점 기록

아래는 최초 계획 리뷰가 시간 초과한 시점의 기록이며, 위 재개 결과로 현재 상태를 판단한다.

### 전용 runtime 확인과 리뷰 중단

기존 배포 archive와 전용 runtime의 파일·링크1701개가 일치했고 추가 파일은 없었다. 격리된 환경의 버전 확인1회는 Python3.14.10·SQLite3.53.1로 성공했다. 실제 설치·관리 진입·sandbox qualification은 아니다. 원 archive와 설치 파일은 바꾸지 않았다.

계획 정적 리뷰는240초 제한에서 응답 없이 중단됐다(exit143, 약240.598초). 입력 drift는 없고 stdout/stderr는 비어 있었다. Reviewer 판정은 없다. 재시도하지 않았고 제품 소스 보정·네이티브 진단·Claude 행동 조회는 시작하지 않았다. 기존129개 소스 입력은 동일하다.

슬롯과 배포 생성기의 Python 허용 목록을 함께 맞춰야 한다. 정확한 macOS 전용 버전만 인정하고 Windows·기타 버전, 무결성·실행 tuple 검사는 유지하는 안이다. raw runtime의9개 내부 symlink와 정규화 배포 입력은 별개로 남긴다.

다음 계획 패킷은 중복된 전체 파일 설명을 제외하고 직접 변경 조건·종료 규칙·조회 경계만 발췌했다. 실패한 원 패킷·원장·로그는 그대로 보존했다. 신규 계획 리뷰360초1회와 이미 예정한 결과 리뷰240초1회를 위해 총 리뷰24→25회, 누적6600→6900초 증액이 필요하다. 기존120분 묶음 잔여·행동 한도11개·2400초·메시지18개는 유지한다. 승인 전 새 리뷰/실행은 하지 않는다.
