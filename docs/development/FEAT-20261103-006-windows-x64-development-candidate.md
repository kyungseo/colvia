# Windows 11 x64 개발 후보 제작

2026-11-03 · 개발 측 제작·집중 검사 완료, Owner 수락.

[Windows 11 x64 공개 준비 계획](CHORE-20261103-003-qualification-alignment.md#win11-x64)의 첫 단계로 기존 Windows 공통 준비본 한 개에서 x64와 ARM64 관리 실행 파일을 빌드했다. 빌더는 기본 ARM64를 유지하며 x64는 `--arch amd64`로 선택한다. 같은 선택으로 전용 CPython 3.14.7 원본의 크기·해시·공급 URL, Go 빌드 대상, 실행기가 요구할 네이티브 아키텍처를 고정한다.

## 개발 측 확인

Go 1.27.2를 사용해 macOS에서 비공개 후보 두 개를 만들었다. 두 관리 실행 파일의 PE32+ 헤더와 Go 빌드 정보가 각각 AMD64·ARM64였다. 실행 파일 안의 제품 ZIP과 카탈로그를 추출 대상 바이트와 대조했다. 두 제품 ZIP 모두 준비된 파일 30개와 관리 모듈이 일치했다. 런타임 카탈로그는 각각 해당 공급 ZIP의 37개 파일과 일치했다. 서로 바꿔 넣은 Python ZIP은 양쪽 빌드 모두 출력 폴더 생성 전에 거부했다.

x64용 Python의 실행 파일·DLL·확장 모듈 33개는 모두 AMD64였다. 기존 ARM64 공급 ZIP에서는 32개가 ARM64였고 `vcruntime140_1.dll` 하나의 헤더가 AMD64였다. 이 파일은 기존 ARM64 카탈로그의 SHA-256과 같다. 처음 검사에서 발견한 차이를 고정 원본과 대조해 기록했다.
