### Installation And Acceptance Disposition

제한된 S1b 수락 대상으로 제시하는 것은 소유한 payload 전달·쓰기 gate, 보정 합성 근거, 지정 macOS worker/probe 관측, 취소/부분 전송 합성 E2E 및 정적 리뷰의 한정된 결과다. Low7 문서 반영을 포함하되 미관측 보호 해결로 표현하지 않는다. 독립 승인·desktop·provider 전체·범용 비밀/인젝션 보호·설치 자격 완료는 수락 범위 밖이다.

새 설치는 선택한 정확한 qualified window를 명시하고, 기존 adopter는 현재 binding·이력·미종결/unknown·실제 노출 old writer·호환 전환을 먼저 확인한다. 공식 v2는 48경로/schema8과 exact v1 predecessor만 허용하며 구 window rollback은 차단한다. 같은 window도 양방향 판독을 검증해야 한다. detach는 capsule과 외부 control 저장소를 지우지 않고, retained authority에 fresh init을 덮어쓰거나 unsupported update를 우회하는 수단이 아니다. 다른 오래된 window 이력이 있으면 detach가 거절될 수 있다. 설치 현황은 미확인이고 실제 adopter 적용은 보류한다.

현재 후보의 설치/업데이트 검증과 미지원 경계 안내는 필수지만 후속 P1/P2 전체 구현은 기본 온보딩의 일괄 gate가 아니다. 실제 provider 또는 민감자료 사용을 제안할 때는 그 경로에 필요한 승인·검증 조건을 별도로 적용한다. 통합 담당은 source/설치물/원격 배포본 identity를 분리하고 repo clone 없는 배포 획득·검증·첫 작업/새 세션 재개·제거 절차를 정확한 후보에 결속한다.

## Owner Result Acceptance — 2026-11-01

Owner가 통합 핸드오프에 명시한 제한과 미완료 항목을 전제로 S1b 결과를 수락했다. 앞선 절의 수락 대기 표시는 각 작성 시점의 역사적 상태이며, 현재 제한된 S1b 결과의 수락 상태는 이 절을 따른다. S1a의 기존 소스·합성 결과 수락도 유지한다.

수락 범위는 trusted-local 호출자·Host·runtime·CLI 전제의 Colvia 소유 payload 전달/쓰기 gate, 보정 합성 결과, 지정 macOS worker/probe 관측, 취소/부분 전송 합성 E2E 및 정적 리뷰·Low7 문서 한정이다. 이는 전체 Guardrails·일반 desktop·독립 사람 승인·같은 UID 우회 방어·provider 전체 전송/보관·범용 비밀/인젝션 방어·실자료·새 후보 설치 자격의 수락이 아니다. 기존 실패·소비 횟수·미관측/미구현·증거 공백은 보존하며 이번 수락을 재시험이나 새 Reviewer 판정으로 표현하지 않는다.

메인은 수락된 제한 결과와 기존 후속 후보7개를 입력으로 통합 계획을 이어갈 수 있다. 후보들은 계획 기록이며 구현은 미선택이다. 공통 Development Index의 정확한 적용 문안은 핸드오프에 있고 현재 index는 그대로다. 실제 통합·새 시험·Claude 전송·설치·Git 작업은 아직 승인되지 않았다. 기존18시간 누적 상한을 유지한다.

Adopter 설치 현황은 미확인이다. 정확한 통합 후보의 inventory/window·old writer·update/rollback/repair/detach 검증과 별도 적용 승인을 거쳐야 한다. 더 넓은 보강 전체를 기본 온보딩의 일괄 선행조건으로 만들지 않는 기존 구분을 유지한다. source와 기존 후보·실패/리뷰 근거는 통합 입력 복원과 검증 재사용 판단이 남아 있어 보존한다.
