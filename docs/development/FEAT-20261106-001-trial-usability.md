상태: Active. Owner가 보정·집중 검사·리뷰와 범위 내 보정을 승인했다. 예상 7–10시간, 누적 상한 12시간. 실제 설치·adopter·Git·공개는 보류한다.

범위: 작업 파일/참고/다른 변경을 구분하는 읽기 화면, 후보 요청 작성 편의, 연결된 Work 상태 표시, 응답과 제목, 명시적 알림 승인 조건, 기존 프로젝트 첫 진입과 설치본 지침. 기존 형식·전체 트리 수락 보호·사람의 결정 권한은 유지한다.

R0: Claude 정적 계획 리뷰에서 표시와 machine output 분리, 검증된 범위 사용, 전체 트리 적용 조건 표시, 승인 소비 경계, canonical 입력 경로 유지가 지적됐다. 모두 반영하되 단일 승인 범위 내 중복 질문 제거와 소비된 실행 승인 재사용은 구분한다. 원본 리뷰와 비식별 시험 상세는 비공개 기록에 보존한다.

현재: 제품 보정과 오프라인 집중 검사는 완료했고 합성 행동 검증은 시험 실행기 경계에서 중단됐다. 전체 묶음 완료·결과 수락 전이다. 아이콘 진단과 정식 Git 연동은 이번 범위 밖이다.
