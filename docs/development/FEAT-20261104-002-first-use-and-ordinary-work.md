# 첫 적용과 일반 작업의 검토

Owner가 첫 진입, 기본 프로젝트 쓰기 범위, 일반 작업 등록·제출, 한 번의 수락, 여러 작업과 연결 해제 안내를 묶어 승인했다. Driver는 제품의 기존 검증·발행 경계를 사용한다. 계획 리뷰는 정적 검토로 진행했다.

계획 검토에서 제기된 경로·판본·권한 문제는 고정 카탈로그의 정확한 이름, 명시한 목표의 현재 선택, 제출 당시 판본, 파일 일치 및 기존 apply 재검사로 다룬다. 같은 로컬 계정에서 실제 사람을 인증한다는 보장은 없다. 범위 밖 변경은 기존 전체 스냅샷 규칙대로 거부한다. 연결 해제 뒤 조회하는 내용은 보존한 기록이다. 실제 병렬 실행, 실제 사용자 설치, 게시 및 플랫폼 지원 확대는 별도다.

## 구현과 확인

- 첫 진입은 관리 도구의 start에서 연결할 폴더와 미리 볼 변경을 안내한다. 빈 폴더, 기존 문서가 있는 폴더에서 미리보기 전후 파일 목록이 일치했다.
- macOS에서 인증한 전용 Python 파일 목록을 메모리에서 대조하고 기존 SHA-256 내용 검사를 그대로 실행한다. 기본 프로젝트 쓰기 프로파일로 검사 저장소 쓰기가 차단된 상태에서 View와 일반 Work의 승인·등록·제출·수락이 동작했다.
- 일반 로컬 파일 편집은 ordinary 명령이 정규 입력과 전체 파일 대조를 작성한다. 범위 밖 수정, 다른 목표의 확인값, 제출 후 파일 변경을 거부했다. 승인 직후 새 대화에서 계획 선택을 다시 읽고, 같은 결정을 재전달해도 기록은 한 건이었다.
- 상위 작업과 하위 두 건의 상태를 보존 기록에서 확인했다. 연결 해제한 별도 실습에서 원본·보고서와 목표·작업 기록 15개는 내용과 모드가 일치했다. 관리 도구가 안내한 조회 경로에서 수락 상태를 읽었다.
- 기존 승인이 있는 합성 FAQ에서 Codex가 수정·검사·제출하고, 새 Claude Code 대화가 같은 결과를 조회해 한 번의 결정으로 수락했다. 첫 응답은 다음 행동이 모호했고, 새 대화의 검토 설명은 길었다. 이후 검토 응답에 결정 질문을 담고 짧은 파일은 변경 내용·중요한 미확인 사항·결정만 보여주도록 보강했다. 이 마지막 문구의 대화 효과는 미관측이다.
- 세 번의 정적 리뷰를 반영했다. 마지막 의견에 따라 보완 요청 시 기존의 정확한 반려와 재작업 경로를 사용하도록 명시했다. 파일을 다시 편집하기 전에 새 기준을 먼저 기록한다. 최종 안내 변경 뒤 추가 독립 리뷰는 수행하지 않았다.

기존 사용자의 갱신 시점은 배포본 검증 후에 결정한다. 현재 사용자 설치는 그대로이며, 이번 작업은 비공개 합성 실습에 한정된다. 실제 병렬 실행, Windows 네이티브 재검증, 일반 사용자 체감 시간은 남는다.
