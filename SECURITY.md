# 보안 문제 제보 · Reporting security issues

한국어 · [English](#english)

Colvia의 취약점을 발견했다면 [GitHub에서 비공개 취약점을 제보해 주세요](https://github.com/kyungseo/colvia/security/advisories/new). 운영체제, Colvia 버전과 재현 순서, 예상되는 영향을 알려 주세요. 실제 자격증명과 프로젝트 자료는 제외하고, 가능하면 합성 자료로 재현해 주세요. 공개 Issues와 PR은 [일반 문의와 버그 신고](CONTRIBUTING.ko.md#질문하거나-버그를-신고하려면)에 사용합니다.

<a id="english" name="english"></a>

## English

If you find a vulnerability in Colvia, [report it privately on GitHub](https://github.com/kyungseo/colvia/security/advisories/new). Include your operating system, Colvia version, steps to reproduce, and possible impact. Leave out real credentials and project data. Use synthetic data to reproduce the issue when possible. Use public Issues and pull requests for [ordinary questions and bugs](CONTRIBUTING.md#questions-and-bug-reports).
