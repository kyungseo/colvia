# Earlier trial reference

[Current user guide](../README.md) · [한국어](../../ko/earlier-profile/README.md) · English

The material in this folder applies to trial builds before the public release. Those builds kept records in a `.hrn/` folder inside the project, and their installation, update and removal procedures and commands differ from the current ones.

**It does not apply to Colvia v0.1.0.** If you are installing or using Colvia now, read the [current user guide](../README.md). Do not run the commands here in a v0.1.0 project.

## Your first project

1. [Write an inquiry report](getting-started.md). Connect a practice folder and draft a report from twelve sample inquiries.
2. [Review a change in the brief](getting-started.md#today--make-the-decision). Check the figures after shipping inquiries are taken out.
3. [Return in a fresh chat](resume.md). Compare yesterday’s draft with the files you have today and find what still needs your attention.
4. [Step away and find your result](resume.md#handoff). Hand off a prepared draft for submission and check the project inbox when you return.
5. [Update or take a break](project-setup.md#maintenance-en). If an update stops or you want to disconnect the project, check what will be kept first.
