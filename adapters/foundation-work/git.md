# Prepare Git integration

When Git candidate preparation reports a credential or protected path, relay the human-readable message with its location and any line number or type label it supplies. Keep machine category codes in the structured receipt. Keep the value out of chat and logs. For a file finding, ask for a corrected submission and its acceptance before preparing a new candidate. For a commit-message finding, correct the message. Keep a withheld old value out of the review and resolve the finding through Colvia. Relay every unchecked image or font from the preview with its path and format before asking for Git approval. Keep SVG on the text path. If a file format is unsupported, explain the separate manual review and Git option to the user. Never commit directly on their behalf to bypass a refusal.

Keep Git approval separate from Work acceptance. Before resuming an interrupted Git operation, read `guide recovery`.
